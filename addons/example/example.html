Sobre este addon

Este é o addon de demonstração do sistema MCBE. Use os arquivos example.html e example.js como modelo para criar novos addons.

Tudo dentro desta div é injetado automaticamente na página de detalhe, ao lado da barra de informações (autor, versão, downloads, tags).

Como instalar

  1. Baixe o arquivo .mcaddon pelo botão "Baixar addon".
  2. Abra o arquivo com o Minecraft Bedrock instalado — ele será importado automaticamente.
  3. Crie um novo mundo e ative o addon em Configurações → Addons.
